## MCQ 1
Question: Which of the following is NOT a core component of the Internet of Things (IoT)?
A) Physical Object (Controller, Sensor, and Actuators)
B) Connectivity (Internet)
C) Artificial Intelligence Algorithms
D) Controller
Correct Answer: C


## MCQ 2
Question:  The IoT Reference Model layer responsible for converting protocols, routing data, and fast-path logic for low-latency decision-making is:
A) Data Accumulation
B) Edge Computing
C) Connectivity
D) Data Abstraction
Correct Answer: B


## MCQ 3
Question: In the context of Machine-to-Machine (M2M) communication, which stage involves interpreting the collected data and deciding on appropriate actions?
A) Transmission of data
B) Collection of data
C) Assessment of data
D) Response to information
Correct Answer: C
